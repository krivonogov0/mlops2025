# Homework: RAG Animation System

## Задание

Реализовать RAG-систему для создания анимаций из текстовых описаний.

**Вход**: текстовый запрос (например, "танец макарена")
**Выход**: GIF анимация

## База данных

`poses_database.json` - 96 поз с описаниями в формате:

```json
{
  "pose": {
    "Torso": [0, 0],
    "Head": [0, 60],
    "RH": [30, 35],
    "LH": [-30, 35],
    "RK": [15, -50],
    "LK": [-15, -50]
  },
  "description": "Руки вытянуты вперед на уровне плеч, ноги на ширине плеч"
}
```

## Критерий оценки

Система должна создать GIF анимацию танца Макарена по запросу "танец макарена".

## Сервисы

Используйте сервисы из предыдущих шагов:
- Ollama (Step 1) - порт 11434
- Pose API (Step 2) - порт 8001

## Как использовать

### 1. Убедитесь, что запущены зависимые сервисы

#### Запустите LLM-сервер (Step 1)

```bash
cd ../step1_vllm_inference
make start  # запускает vLLM на http://localhost:8000
```

#### Запустите Pose API (Step 2)

```bash
cd ../step2_function_calling
make start-all  # запускает Pose API на http://localhost:8001
```

### 2. Установите зависимости проекта

```bash
poetry install
```

### 3. Запустите генерацию анимации

```bash
# Сгенерировать танец макарена (по умолчанию)
poetry run python main.py

# Или указать свой запрос
poetry run python main.py "T-поза с прыжком"
```

### 4. Результат

- Анимация сохраняется в папку `outputs/`
- Файл называется по запросу, например:  
  `outputs/танец_макарена.gif` или `outputs/T-поза_с_прыжком.gif`

### 5. Требования к окружению

- Poetry
- Доступ к LLM-серверу с прошлого шага (Ollama/vLLM)
- Доступ к Pose API (порт 8001)
